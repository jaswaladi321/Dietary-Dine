# Dietary-Dine

A dietary-friendly restaurant discovery web platform built by **Team Code Blooded** for **CSE326 (Internet Programming)** at **Lovely Professional University (LPU)**. It helps users browse and filter restaurants by dietary categories (such as Vegan, Gluten-Free, Halal, and Keto) and location/city using semantic HTML5, responsive CSS3 layouts, and client-side JavaScript.

## Features & CSE326 Highlights
- **Dietary & Location Filtering:** Discover restaurants filtered by dietary preferences (Vegan, Gluten-Free, Halal, Keto, and related categories) and city/location.
- **Dedicated Pages & Views:** Separate interfaces for restaurant discovery (`index.html`) and user login/signup (`login.html`, `login_signup.html`).
- **Responsive Styling:** Custom stylesheets (`index.css`, `style.css`, `login_signup.css`) for layout structure, typography, and screen adaptability.
- **DOM & Event Handling:** Client-side JavaScript (`app.js`, `index.js`, `login_signup.js`) driving interactive filtering, UI state updates, and authentication button handling.
- **Visual Assets:** Custom food imagery and media assets (`food-image 1.png`, `food-image 2.png`, `src/`, and `assets/`).
